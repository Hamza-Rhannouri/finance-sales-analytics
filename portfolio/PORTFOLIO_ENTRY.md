# Portfolio Entry — Finance Sales & Profitability Analysis

## Summary
Built an end-to-end finance analytics solution using Excel/Power Query and Power BI. Starting from a deliberately inconsistent sales dataset, I performed data-quality remediation, applied business rules to geographic fields, reconstructed missing financial measures, modeled the data using a star schema, created financial KPIs with DAX, and built a multi-page dashboard focused on profitability and performance drivers.

## Tools
- Excel / Power Query / M
- Power BI
- DAX
- Star-schema dimensional modeling

## Key analytical areas
- Revenue and profit
- Gross profit and margin
- Sales and product performance
- Geographic performance
- Cost structure
- Executive recommendations

## What this project demonstrates
Data cleaning, business-rule reasoning, financial modeling, dimensional modeling, DAX, data visualization, and business storytelling.
