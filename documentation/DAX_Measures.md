# DAX Measures

Documented measures from the project:

```DAX
Margin = DIVIDE([Profit], [Revenue]) * 100

Gross Profit = [Revenue] - [COGS]

Gross Profit Margin = DIVIDE([Gross Profit], [Revenue]) * 100
```

The model also contains the measures used by the Power BI report. The `.pbix` file remains the primary executable artifact.
